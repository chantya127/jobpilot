How to get a Gmail app password (2 minutes)
  1. Turn on 2-Step Verification: myaccount.google.com/signinoptions/twosv
  2. Open myaccount.google.com/apppasswords
  3. Type a name such as JobPilot and press Create.
  4. Copy the 16-character code, paste it here, then press Save and Test connection.

Use the same Gmail address that you apply with. You can revoke the app password at any time on the same page. Google Workspace accounts may need an admin to allow app passwords.
